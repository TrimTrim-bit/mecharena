# Project instructions

MECH ARENA is a browser-only React 19 game built with Vite, TanStack Router,
Tailwind CSS, and Three.js. It has no server or account requirement: pilot
progress is stored in browser local storage.

## Structure

- `index.html` is the static browser entry point.
- `src/main.jsx` mounts the client-side app.
- `src/routes/` contains file-based TanStack Router routes.
- `src/lib/` contains game data, local pilot storage, arena logic, maps, and
  progression helpers.
- `src/components/` contains the game UI and shared controls.
- `src/routeTree.gen.ts` is generated by the router plugin. Never edit it by
  hand.

## Development and publishing

- `npm run dev` starts the local development server.
- `npm run lint` checks the JavaScript and JSX.
- `npm run build` creates the static website in `dist/`.
- Upload only the contents of `dist/` to a static website host.
- `npm run preview` serves the production build locally.

The app uses hash-based routing so direct page refreshes work on static hosts
without URL rewrite support. Do not add server routes, secrets, or required
backend services unless the project is intentionally being redesigned.

## Change conventions

- Write JavaScript and JSX only; no TypeScript source files.
- Keep changes focused and preserve existing game behavior.
- Use existing components, Tailwind patterns, and localStorage pilot helpers.
- Validate changes with `npm run lint` and `npm run build`.
- Do not commit generated build output or `node_modules/`.
